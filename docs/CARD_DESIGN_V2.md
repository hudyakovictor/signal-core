## 1. ЦВЕТОВАЯ СИСТЕМА (4 типа → 4 цвета)

Цвет карты = **функциональная роль в процессе принятия решения трейдера**.
Выбор цветов исходит из:

- цветовой семантики (синий = анализ/информация, зелёный = действие, фиолетовый = правила, золотой = защита);
- цветового контраста на тёмном фоне UI (референс: `примеры карт.png`);
- аркадной читаемости: игрок на 0.3 сек должен понять тип карты по цвету рамки.

| Тип | Цвет рамки | Hex | Семантика | Кол-во |
| :--- | :--- | :--- | :--- | :--- |
| **READ** | Синий (Ice Blue) | `#38BDF8` | Чтение рынка, сбор данных, наблюдение | 14 |
| **DECIDE** | Зелёный (Neon Green) | `#4ADE80` | Конкретное торговое действие / решение | 9 |
| **PROTOCOL** | Фиолетовый (Violet) | `#A78BFA` | Правило системы, ментальный протокол | 10 |
| **PROTECT** | Золотой (Amber) | `#FBBF24` | Защита от ошибки, стоп-правило | 7 |

**Логика выбора цвета рамки** (в отличие от старой монохромной системы, где цвет = категория содержания):

- Рамка цветная, яркая (glow-эффект ~10px blur, opacity 0.7).
- Фон карты всегда тёмный `#0D1117` (космос).
- Иконка монохромная белая (как в старой системе SVG) — это сохраняет «DNA» проекта.
- Номер карты и название — белый текст.

## 2. ПОЛНЫЙ СПИСОК 40 КАРТ С ИКОНКАМИ

### Логика подбора иконок

Каждая иконка:

1. **Моментально читается** при 48×48px (нет мелких деталей, нет текста).
2. **Не дублирует** соседние карты в колоде.
3. **Семантически точная** — образ = суть навыка трейдера.
4. **Существует** в Lucide Icons / Heroicons / Tabler Icons (open source, использовались в старых SVG).
5. В скобках — тип иконки + альтернативный образ на случай замены.

## 3. SVG-ШАБЛОН КАРТЫ (новая версия)

Карта нового образца отличается от старой:

- **Цветная рамка** вместо монохромного контура.
- **Glow-эффект** по типу карты.
- **Цветной бейдж типа** (READ / DECIDE / PROTOCOL / PROTECT) в правом нижнем углу.
- Иконка остаётся **монохромной белой** (DNA проекта сохранён).

```
┌─────────────────────────┐  ← рамка цветная (тип)
│  [01]                   │  ← номер карты
│                         │
│       [ICON 48px]       │  ← монохромная белая иконка
│                         │
│   MARKET STRUCTURE      │  ← название белым
│   ─────────────────     │
│   READ             [●]  │  ← бейдж типа + индикатор уровня
└─────────────────────────┘
```

**Цвета glow по типу:**

```css
--color-read:     #38BDF8;  /* box-shadow: 0 0 12px #38BDF8aa */
--color-decide:   #4ADE80;  /* box-shadow: 0 0 12px #4ADE80aa */
--color-protocol: #A78BFA;  /* box-shadow: 0 0 12px #A78BFAaa */
--color-protect:  #FBBF24;  /* box-shadow: 0 0 12px #FBBF24aa */
```

Готовые токены и базовые классы (`.skill-card`, `[data-card-type]`, `.entity-card`)
лежат в [`apps/game-client/src/styles/card-tokens.css`](../apps/game-client/src/styles/card-tokens.css).
