# Privacy Policy (draft)

## Data collected

- **Game telemetry**: battle outcomes, card plays, session duration (stored server-side).
- **Telegram initData**: user ID, auth date (validated server-side, not stored).
- **Device fingerprint**: device model, platform (for anti-cheat).

## Data usage

- Improve game balance and anti-cheat.
- Prevent fraud and abuse.

## Data retention

- Telemetry: 90 days rolling.
- Anonymized aggregates: indefinite.
