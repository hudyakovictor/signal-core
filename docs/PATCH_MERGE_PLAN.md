## Порядок применения

1. `git apply --check` каждого патча на чистый каркас `apps/game-client`.
2. Базис: 01a08e29 накатывается первым на пустой src.
3. Поверх — 01a08e1c (UI/RexUI) с ручным разрешением конфликтов в общих файлах.
4. Затем — 01a08e14 (save/ассеты) и 01a08e0b (телеметрия/PWA).
5. После каждого шага — `npm run typecheck` и `npm run build` (Vite) как ворота качества.

## Правила разрешения конфликтов
- Общие файлы (SignalArenaScene.ts, data.ts, main.ts) — сверять построчно, приоритет у базиса 01a08e29.
- Уникальные модули каждой сессии переносятся без изменений.
- Дубликаты типов — сводятся в packages/shared-types.
