# Tutorial — первые 5 минут

## 0:00–0:30 — Лендинг
- Игрок заходит на `/`, видит заголовок "Signal Arena", кнопку "Играть".
- Клик → переход на `/game`, загрузка Phaser.

## 0:30–1:00 — Вступление Скрепки
- Появляется Скрепка: "Кажется, ты собираешься слить депозит... Я пришёл из прошлого..."
- Кнопка "Понятно" → переход к бою.

## 1:00–2:00 — Первый бой (FOMO Wraith)
- Скрепка объясняет: "Держи курсор на цели, не тапай без сигнала."
- Игрок парирует 3 атаки, побеждает босса.
- Награда: 100 Focus.

## 2:00–3:00 — Магазин карт
- Скрепка: "Теперь у тебя есть Focus. Купи карту 'Стоп-лосс барьер'."
- Игрок покупает карту, видит описание.

## 3:00–4:00 — Второй бой (Leverage Goblin)
- Скрепка: "Гоблин предложит x50. Не ведись."
- Игрок игнорирует множитель, парирует, побеждает.

## 4:00–5:00 — Дейлик
- Скрепка: "Заходи завтра — будет новый босс и дейлик."
- Кнопка "Вернуться на лендинг".

## Метрики успеха
- 90% игроков проходят первый бой.
- 70% покупают первую карту.
- 50% возвращаются на следующий день (D1 retention).
